# Skills

A collection of custom [agent skills](https://docs.anthropic.com/en/docs/claude-code/skills).

## Available skills

| Skill | Description |
| --- | --- |
| [gh-cli](skills/gh-cli/SKILL.md) | GitHub CLI reference for repositories, issues, pull requests, Actions, projects, releases, gists, codespaces, and more. |
| [git-commit](skills/git-commit/SKILL.md) | Create Git commits with Conventional Commits analysis, safe staging, and concise message generation. |
| [issue-pr-writing](skills/issue-pr-writing/SKILL.md) | Write concise issue, pull request, and merge request titles, bodies, and comments. |
| [web-access](skills/web-access/SKILL.md) | Route agents without built-in web tools to MCPorter, Exa MCP, agent-browser, or direct fetch. |
